# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 1.0     | ✅        |
| 1.1     | ✅        |

## Reporting a Vulnerability

If you find a security vulnerability in LibYGT, **please do NOT open a public issue!**

Instead, contact us privately:
- E-mail: yigitinstudyoo@gmail.com

## What to include
- Description of the vulnerability
- Steps to reproduce
- Your OS and compiler version

## Response
We will respond as soon as possible and fix the issue in the next release.
